ÉCART
Six cases pour le code : un composant neuf
A1 dessine six cases ; le plan (research R-21) refuse un composant neuf pour un gain visuel. Le code est un champ nombre du canon, IBM Plex Mono espacé, inputmode numérique et autocomplete one-time-code. Si les cases sont voulues, c’est un composant de plus au système, donc un arrêt de cycle.
ÉCART
Avant la session, qui est « l’établissement » ?
A1 nomme « Les Palmiers » sur l’écran du numéro et donne le numéro du secrétariat. Or le tenant n’est pas connu avant la session (R-14 : l’indicatif vient du déploiement pour cette raison). Le contrat § 1.9 ne sert le contexte qu’après. D’où viennent le nom et le numéro +225 27 22 41 18 90 de la carte « Le SMS n’est pas encore arrivé ? » ? Configuration du déploiement, ou la carte sans numéro : à trancher avant le plan des écrans.
ÉCART
Deux mots pour une même chose
La spec écrit « message court » (et cite « Plus tard : me connecter par message court ») ; A1 et la pastille de canal disent « SMS ». Les écrans ci-dessus disent « SMS » à la personne ; le lexique doit fixer le mot visible.
ÉCART
« École » est un mot refusé
A1 : « messages de l’école ». Le lexique dit établissement, jamais école. Les écrans ci-dessus corrigent.
