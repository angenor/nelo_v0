US3 · Le code personnel
T1a · US3 · le code personnel remplace le message court sur un appareil connu

Pourquoi avant quoi, deux saisies, « Plus tard », puis quatre chiffres et un nom

Après la première ouverture par code reçu, l’écran dit à quoi sert le code personnel avant de le demander. Ensuite, sur cet appareil, la personne ouvre avec son nom et quatre chiffres : aucun message ne part, aucun numéro n’est affiché, et un code saisi n’est jamais réaffiché. Sur un appareil inconnu, le code personnel n’est pas proposé : le parcours par SMS l’est.

Définir son code personnel

Le refus de format est annoncé pendant la saisie (« Quatre chiffres, rien d’autre »). « Plus tard » ramène au SMS à chaque ouverture, sans pénalité.

Le domaine gagne

A1, « Ouvrir avec l’empreinte digitale » et le pavé numérique dessiné. Le domaine dit : téléphone et code reçu, code personnel pour les usages fréquents (02-domaine.md § 3.1). Aucune biométrie n’est livrée ni proposée (FR-025) ; le pavé est un composant neuf que R-21 refuse.

QUESTION OUVERTE
Que lit un compte suspendu ?
Un code personnel saisi pour un compte suspendu répond AUT_COMPTE_SUSPENDU et l’appareil oublie le compte (scénario 8). La spec donne le code, pas le mot d’écran ni son versant positif. Sans réponse, l’écran retombera sur le parcours par SMS, qui ne répond rien non plus : la personne ne saura pas qu’elle doit voir l’administrateur.
ÉCART
Le mot du lien « Plus tard »
La spec cite « Plus tard : me connecter par message court » ; A1 écrit « Plus tard, me connecter par SMS » avec un tiret cadratin entre les deux membres, signe que le projet interdit. Le libellé ci-dessus suit la spec ; le lexique tranchera « SMS » ou « message court » (voir US1).
