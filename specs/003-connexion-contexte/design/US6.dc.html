US6 · Le lien d’activation
T1a · US6 · activer son compte depuis un lien à usage unique

Un message court rédigé pour le message court, un lien qui ne sert qu’une fois, et le code reçu comme second chemin

Le secrétariat crée le compte à partir du numéro ; la personne reçoit un lien, l’ouvre, son compte s’active, sa session s’ouvre et l’appareil devient connu. Le lien perdu n’est pas un compte perdu : entrer son numéro et recevoir un code active tout autant (FR-033).

Le message court

Sous 160 caractères, avec le nom de l’établissement, sans abréviation ; fr et en naissent ensemble (FR-009, FR-030). Le lien compte dans les 160 : la longueur ci-dessous est celle du texte, le lien en plus.

« Lien déjà utilisé ou expiré », deux issues

Une information, pas une faute. L’issue principale active le compte par le numéro ; la seconde renvoie au secrétariat.

18:022G
Activation

Ce lien ne fonctionne plus

Un lien d’activation ne sert qu’une fois et vaut sept jours. Rien n’est perdu : votre compte s’active tout autant avec un code reçu par SMS.

Deux façons de continuer
Entrez votre numéro pour recevoir un code : posséder le numéro est la preuve, quel que soit le canal. Ou demandez un nouveau lien au secrétariat de votre établissement.
ÉCART
Le secrétariat du lien invalide n’a pas de numéro
Un lien consommé ou expiré n’identifie plus sûrement son tenant ; la personne n’a pas de session. L’écran ne peut donc pas écrire le numéro du secrétariat, à la différence de ce qu’A1 faisait. Même question qu’en US1 : configuration du déploiement, ou le mot sans numéro.
ÉCART
« Compte activé » est un mot d’état sans code
Le bandeau reprend la forme « Numéro vérifié » d’A1, en voix de réussite. L’état du compte, invite → actif → suspendu (02-domaine § 16), n’a pas de code dans ETATS_METIER ni de mot dans le lexique ; les pastilles « Invité » et « Actif » ci-dessous sont dessinées en ocre et réussite par analogie, à inscrire au registre.
QUESTION OUVERTE
Le lien ouvert dans un navigateur de poste
Il fonctionne, et rend ce poste connu du compte pendant securite.appareil_connu_jours. Un responsable légal qui ouvre son lien sur le poste du secrétariat y laisse un appareil connu : aucune gestion de ses appareils n’est livrée (hors périmètre). À dire dans le message du secrétariat.

Au secrétariat : créer, renvoyer, et ce qui est absent

La réponse de création dit « invitation envoyée le … », jamais le lien. Sur un compte actif, l’action de renvoi n’existe pas : elle n’est pas grisée.
