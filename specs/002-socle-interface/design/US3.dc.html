T0b · US3 · la coquille se compose depuis le contexte

Quatre situations, dérivées des capacités, jamais d’un rôle

Le contexte de GET /moi/capacites (compte, établissements et leur administrateur, année, capacités, pack, alertes) compose la coquille. Le domaine d’une capacité est le premier segment de son code. Un domaine sans capacité est absent : aucun menu grisé nulle part.

04

Aucune capacité : pas de navigation, un message qui nomme l’administrateur

Le compte est connecté, aucun domaine n’est attribué : pas de barre latérale, pas de menu, pas de page vide, pas d’erreur technique. Le message nomme l’administrateur de l’établissement, donne son téléphone et propose une action.
